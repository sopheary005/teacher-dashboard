# ផ្ទាំងគ្រប់គ្រងទិន្នន័យគ្រូបង្រៀន (Teacher Dashboard)
**វិទ្យាល័យព្រះយុគន្ធរ សាលារៀនជំនាន់ថ្មី (NGS)**  
**អ្នកគ្រូបង្រៀន៖ ថោង សុភារី (Teacher Pheary)**  
**ឆ្នាំសិក្សា៖ ២០២៦-២០២៧**

## 🌟 លក្ខណៈពិសេស (Features)
- 🎨 **ការរចនាយ៉ាងប្រណិត** ពណ៌ស្វាយ-ផ្កាឈូក NGS Gradient
- 👩‍🏫 **ព័ត៌មានផ្ទាល់ខ្លួនរបស់អ្នកគ្រូ ថោង សុភារី** និងរូបថតជាក់ស្តែង
- 🕒 **នាឡិកា Live Clock** ម៉ោងផ្ទាល់ជាភាសាខ្មែរ និងលេខខ្មែរ
- 📋 **ប្រព័ន្ធហៅឈ្មោះសិស្ស** (ថ្នាក់ 9NGS-B2 / 8NGS-B2)
- 🎯 **ចាប់ឈ្មោះសិស្សឆ្លើយសំនួរ** (Random Student Picker)
- ⏱️ **នាឡិកាកំណត់ពេលបង្រៀន** (Classroom Timer / Stopwatch)
- 📝 **កត់ត្រាកិច្ចការ និងកំណត់ចំណាំ** (រក្សាទុកលើ LocalStorage)
- 🎮 **ល្បែងគណិតវិទ្យារហ័ស** (Speed Math Challenge)
- 💾 **បម្រុងទុកទិន្នន័យ (Backup JSON)** និងបោះពុម្ព (Print)

## 🚀 របៀបបង្ហោះជា Web លើ GitHub (GitHub Pages) ដោយឥតគិតថ្លៃ

### ជំហានទី ១៖ បង្កើតគណនី GitHub (ប្រសិនបើមិនទាន់មាន)
1. ចូលទៅកាន់គេហទំព័រ [github.com](https://github.com)
2. ចុច **Sign up** រួចបញ្ចូល Email, Password និង Username របស់អ្នកគ្រូ
3. ផ្ទៀងផ្ទាត់ Email ឱ្យបានជោគជ័យ

---

### ជំហានទី ២៖ បង្កើត Repository ថ្មី
1. ពេល Login ចូល GitHub រួច ចុចសញ្ញា **+** នៅជ្រុងខាងស្តាំខាងលើ ហើយជ្រើសរើស **New repository**
2. នៅត្រង់កន្លែង **Repository name** វាយឈ្មោះ: `teacher-dashboard`
3. ជ្រើសរើសយក **Public**
4. គូសធីកលើ **Add a README file**
5. ចុចប៊ូតុងពណ៌បៃតង **Create repository**

---

### ជំហានទី ៣៖ Upload ឯកសារទាំងអស់ចូល GitHub
1. នៅទំព័រ Repository ដែលទើបបង្កើតរួច ចុចលើប៊ូតុង **Add file** -> ជ្រើសរើស **Upload files**
2. ចូលទៅកាន់ Folder ក្នុងកុំព្យូទ័ររបស់អ្នកគ្រូ៖ `D:\2026-2027\Teacher Dasbord\`
3. អូសទាញ (Drag & Drop) ឯកសារ និង Folder ទាំងអស់បញ្ចូល៖
   - `index.html`
   - `photo_2026-10-30_18-06-42.jpg`
   - Folder `css/` (ដែលមាន `style.css`)
   - Folder `js/` (ដែលមាន `app.js` និង `tools.js`)
4. ចុចប៊ូតុងពណ៌បៃតង **Commit changes**

---

### ជំហានទី ៤៖ បើកដំណើរការ GitHub Pages (យក Link ផ្សាយផ្ទាល់)
1. នៅលើទំព័រ Repository ដដែល ចុចលើ **Settings** (រូបកង់ធ្មេញ) នៅខាងលើ
2. នៅម៉ឺនុយខាងឆ្វេង រកមើលពាក្យ **Pages**
3. នៅត្រង់កន្លែង **Branch** (ក្រោមចំណងជើង Build and deployment)៖
   - ប្តូរពី `None` ទៅជា **`main`** (ឬ `master`)
   - ជ្រើសរើស Folder: **`/ (root)`**
4. ចុចប៊ូតុង **Save**
5. រង់ចាំប្រហែល ១ ទៅ ២ នាទី រួច Refresh ទំព័រនោះ អ្នកគ្រូនឹងឃើញ Link ពណ៌ខៀវលេចឡើង ឧទាហរណ៍៖
   👉 `https://username.github.io/teacher-dashboard/`
